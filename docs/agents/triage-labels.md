# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| Needs evaluation | needs-triage | Maintainer review needed |
| Needs information | needs-info | Waiting for more information |
| Agent-ready | ready-for-agent | Fully specified for agent implementation |
| Human-ready | ready-for-human | Requires human implementation |
| Declined | wontfix | Will not be actioned |

Readiness labels do not override blocking dependencies.
